# 📊 HR Analytics Dashboard | Power BI

An interactive Power BI dashboard designed to analyze workforce performance, employee attrition, demographics, salary trends, and job satisfaction. The dashboard helps HR professionals monitor key workforce metrics and support data-driven business decisions.

# Project Overview

This HR Analytics Dashboard was developed to provide a comprehensive view of organizational workforce analytics. It combines employee demographics, attrition analysis, salary insights, and satisfaction metrics into a single interactive report for effective HR decision-making.

---

# Key Performance Indicators (KPIs)

| KPI | Description |
|------|-------------|
| **Total Employees** | Total workforce in the organization (1,470). |
| **Attrition** | Total employees who left the company (237). |
| **Attrition Rate** | Overall employee turnover rate (16.12%). |
| **Active Employees** | Current employees actively working (1,233). |
| **Average Age** | Average age of employees (37 years). |

---

# Dashboard Components

| Visualization | Purpose |
|--------------|---------|
| **KPI Cards** | Provides an executive summary of workforce metrics. |
| **Attrition Distribution** | Department-wise employee attrition using a pie chart. |
| **Age Group Analysis** | Gender distribution across different age groups. |
| **Gender by Department** | Employee count comparison across departments. |
| **Salary Hike Analysis** | Department-wise salary comparison. |
| **Job Satisfaction Matrix** | Satisfaction ratings for different job roles. |
| **Environment & Relationship Satisfaction** | Combined view of satisfaction and monthly income. |

---

# Key Insights

- **R&D** contributes the highest employee attrition (**56.12%**).
- The **25–34** age group represents the largest workforce segment.
- **R&D** is the largest department with **961 employees**.
- Higher salary allocation does not necessarily reduce employee turnover.
- Job satisfaction analysis helps identify roles requiring improved engagement and retention strategies.
